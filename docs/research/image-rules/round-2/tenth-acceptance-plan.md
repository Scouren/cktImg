### Caller-first seam, before geometry capability

The following is proposed usage, not existing API names. The smallest first
trial can invoke the concrete collector from a test/diagnostic adapter using
the staged API; ordinary `place` keeps its current signature. Do not duplicate
the 4N pin table simply to serialize a research record.

```text
native selected-cell caller:
    early = existing parser records selected cell, complete model/declaration
            facts and original directive source spans before normalization
    sources = existing deckSources transform; tag synthetic roles/stays separately
    nl, roles = existing parse/role stages(sources)
    context = bind early cell/formal/device/net references to this exact nl
    parents = structure.collectParents(scratch, nl, context)  # O0, no movement
    caller = existing admission result plus original request identities
    future arrangement admission consumes parents + caller
    K/C later verifies the actual selected class only for an admitted proposal

plugin cell caller:
    early = selected Deck cell, port_net/dev_net slices, dev_rest and original
            code/code_cell + directives, captured before cellDeck translation
    library = existing layout.library(...)                   # retains authority
    text = existing cellDeck(...); retain original→generated device/net map
    nl = existing engine parse(text)
    context = bind early complete facts through that exact mapping
    if source/model/caller authority is unavailable: decline new collector only
    parents = same concrete collectParents(scratch, nl, context)
    future K/C uses actual recognized/caller library geometry, not generated names
```

Early syntax qualification, caller admission and actual class capability are
three different decisions. The plugin `Deck.models` preserves a sequence and
`modelKind` uses the first definition; native `Netlist.models` uses the last
stored definition. The experimental duplicate-declaration decline must read
the original declaration facts, not choose either normalized interpretation.
Plugin `Deck.code` preserves original model statements, but their selected-cell
scope and mapping still need validation. This is a concrete second caller for
the context seam, not evidence that transport has been implemented.

Use borrowed incidence/parameter slices and a bounded cold context owned by
the caller for the analysis lifetime. Missing or mismatched context returns
an unsupported experimental result. Existing ordinary rendering continues;
no `b`-name inference, per-device hot provenance flag, callback framework or
universal ABI extension is needed. Actual plugin/ABI support can remain a
separately pending target gate for the native O0 prototype.

## Storage, change radius and finish lines

O0 borrows typed device/net handles, complete ordered incidences and the cold
context witness. One structure-analysis owner publishes parent membership,
member CSR and typed gate-interface rows. With N devices, at most N parents,
N member references, 4N MOS incidences and N gate rows are needed for this
cohort; capacities are not eleven candidates or five AG1080 groups. The
existing library owns geometry. Search scratch is temporary; no second
authoritative coordinate table or hot presentation flag is needed.

The smallest implementation radius is the selected-input context producer,
one concrete local-parent collector, structure-analysis publication and
test adapters/oracles. Existing mates, skeleton, routing, ABI and plugin
geometry remain consumers of their existing inputs for O0. A different
parent arrangement changes G later; a different physical partition changes
N/W later; a new glyph changes K/C later. None requires putting these policies
inside this collector. Persisting new runtime metadata must still justify
its range, lifetime and capacity under the repository's data rules.

The O0 native prototype finishes when all exact corpus dispositions and selected complete facts
match; all named mutation/boundary/atomicity tests pass; current native drawing
outputs are unchanged; and caller controls retain their named results. A
production release additionally requires the same-build target gate to confirm unchanged ordered electrical exports for
AG1080/928 and selected decline controls. Compare the actual target netlist
as well as its equivalence verdict. The older-host research cannot substitute
for that new artifact. Normal repository renderer/style/ABI/WASM/size and PR
