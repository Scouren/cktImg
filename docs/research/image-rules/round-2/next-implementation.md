# Next implementation and a finite visible finish line

Implement complete local-parent collection first, then pursue the six exact
source wire partitions below as the first visible milestone. Test local
arrangements in a separate diagnostic branch of the pipeline. The collection
step has a concrete oracle today. The twelfth study supplies a narrow local
organization postcondition; full arrangement feasibility remains unproved.
None of these production steps is implemented by the research scripts.

The [27 conditional rules](proposed-human-rules.md) describe the wider agenda.
This file chooses an order; the [package plan](implementation-packages.md)
defines ownership and dependencies. Runtime decisions use circuit facts and
admitted caller intent. Case names below identify tests only.

Use the existing selected-cell parser boundary to retain the original model
declarations, selected formals and caller provenance before normalization
discards their distinctions. Bind that cold context to the exact netlist and
borrow its ordered pins and parameter slices. Do not add a second SPICE parser

[acceptance plan and manifest](tenth-acceptance-plan.md). It returns complete

not change coordinates, mate semantics, class selection, request verdicts or
wiring. Keep capacity and search completeness separate: two complete distinct
witnesses can prove ambiguity; one witness cannot prove uniqueness after
exhaustion. Allocation failure remains an operating error.

Keep search outcome, complete raw facts and later policy eligibility separate.
A certified parent cycle declines the initial arrangement/partition policy;
it must not erase the already collected parent/interface facts needed to retain
AG1053 as a raw contrary. Incomplete search still cannot publish unique ownership.

The first green checkpoint requires:

* The exact seven disposition-name sets for all 2,202 decks, with their reasons
  and the complete expected parent/interface records. Counts alone do not pass.
* AG1080's five complete parents, AG928's one-core keep, AG1037's reflected
  one-parent result, all eleven raw multigroup cases and both cycle declines.
* The retained duplicate-model, continued-formal, unused-formal, body, passive,
  model-parameter, renaming, card-order and exhausted-search controls.
* Unchanged ordinary rendering and caller results before versus after O0 on
  the same current implementation baseline and exact comparison cohort. The
  frozen 81-header engine supplies research evidence; it is not a demand that
  the current 84-header engine reproduce that older geometry. No existing
  global-axis field is repurposed for local axes.

This is an internal analysis milestone. Calling it complete does not mean the
user's flattened comparator drawing has improved.

## 4. Promote only the artifact that passed

The native gallery experiment and actual target support have distinct checkpoints.
Native JSON pin preservation is not a target round trip, and an electrical
comparator can miss swapped ports on an empty block. Require complete ordered
binding checks as well as actual Schemify netlisting/comparison and final
physical/contact checks on the same build being promoted.

For N0 target support, transport the complete original cell/caller context
through the plugin and prove all six actual target conductor/name partitions,
including the contrary caller and cycle controls. A plugin lacking that
authority may legitimately retain its ordinary path. Even if it netlists the
same circuit, that fallback is not a repaired plugin drawing. A native gallery
pass must therefore be labelled native-only until these target gates pass.

Before a merge, run both renderer configurations, style/formatting, applicable
native/ABI/plugin checks, gallery inspection and reproducible committed WASM
within the existing 550 KB cap. Existing known physical regressions and the
oversized experimental module remain release blockers. A research proof or
older-target pass cannot waive them.

The broader symbol, signed-slot, body-presentation and diagonal packages remain
independent workstreams where their capabilities are needed. They do not all
have to finish before the existing-MOS experiment. Whole-corpus equivalence
requires addressing the remaining named cases; this finite milestone is an
explicit intermediate finish line.
