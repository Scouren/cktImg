# Fourth body round: all 23 actual source certificates

**All 23 named body-only cases pass the extended physical source proof.** The previous three-representative limit was a scope limit. The source conclusion remains 22 explicit dashed B-to-B bridges and one omission, AG1236. The [fourth certificate](fourth-bodies-evidence.json) has `unsupported=[]` and lists every certified name. The third-study artifacts remain unchanged and retain their original narrower claims.

The exact cases are AG1236, AG1294, AG1296, AG1297, AG1299, AG1307, AG1313, AG1319, AG1329, AG1335, AG1337, AG1343, AG1399, AG1404, AG2193, AG2285, AG2287, AG2315, AG2397, AG2463, AG2464, AG2490, and AG2498. Every enlarged source/native pair was already actually viewed in the [third-study ledger](third-bodies-views.json). This round extends their geometry certificates; it does not invent a new image-view count.

The [checker](fourth-bodies-proof.py) now establishes, for every case:

- Exact raw ordered D/G/S/B and model agreement with manually transcribed card literals. Each model declaration is exactly `.model pch pmos`; unsupported or contradictory declarations fail the narrow family gate.
- Complete raw incidence of the body net is exactly the two named B occurrences. The node is internal and distinct from both devices' D/G/S; their common source is a separate node.
- Both actual instance labels match the literal raw card names. Unique glyph type/origin and 138 total actual D/G/S endpoints are checked.
- An independent actual-role frame identifies the source branch from the PMOS arrow polygon, the drain from the opposite outer branch, and the gate from its outer horizontal lead. This is restricted to the observed upright PMOS family. It rejects a cached D/S swap that mere endpoint membership would accept.
- All 46 cached B points lie in their own actual channel polygons. None is an own fourth line/polyline endpoint. This is a supported source landing convention, not a generic four-lead symbol capability.
- Each of the 22 visible cases has one exact named cache segment present in actual SVG conductor ink, one literal direct B-to-B SVG segment with `stroke-dasharray="3 3"`, and both a named-stroke and all-actual-ink path between the supported body points.
- AG1236 has no cached body wire segment, no actual conductor through either supported B point, and neither named nor all-ink B-to-B connectivity. Its solid source arch is separately identified.
- There are zero cached body segments missing from source ink in the original 23 cases and zero exact literal text labels matching the internal body-net names. The latter is a literal-label result, not a proof that every conceivable textual convention is absent.

Deleting only the direct actual body bridge independently in each of the 22 explicit cases changes both connectivity results to false. The unchanged cache then produces the exact missing segment, demonstrating that source metadata cannot fabricate the actual connection. These are 22 actual-source mutations, not comparisons between precomputed lists. Further mutations change AG1294's actual instance label, duplicate its actual glyph, and swap cached D/S points; all are rejected by the corresponding identity, uniqueness, or arrow-frame gate.

This strengthens the denominator behind the [third-study conditional plan](third-bodies.md). A distinct body-only net can have an explicit source bridge even though it has no ordinary signal driver or external port. The same raw topology can also be omitted by the source. An explicit source-convention request and the default complete representation remain separate policy inputs. Neither changes the ordered electrical node. The full 23-case physical denominator supports that distinction; it does not establish an automatic stylistic preference from topology.

The new actual-arrow check is deliberately narrow. It must not become a global assumption that every PMOS source points upward, nor may a cached `source_dir` substitute for the actual arrow. Other glyph families, rotated frames, aliases, or ambiguous primitives must get an explicit supported frame or a named unresolved result. Per-family source-role witnesses are stronger than checking that cached coordinates occur somewhere among a glyph's endpoints.

The semantic names of source wires still come from raw/cache correspondence. Literal instance labels and actual source-arrow roles now corroborate device identity and D/G/S order in this set, but external marker text-to-formal binding remains outside this certificate. The known AG1014 VI1-to-VI2 text mutation is not closed by this work. The next bounded study addresses that separate association. No C ABI execution, host round trip, circuit-operation conclusion, production edit, or compiler run is claimed.
