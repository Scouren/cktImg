# Eighth body round: admission of supported SVG visibility state

The fifth body certificate remains unchanged. It proves ordered bindings,
object-owned marker text and paths through supported primitive coordinates.
It did not evaluate SVG display authority. Six actual AG1014 mutations expose
that boundary: the old proof accepts hidden VI1 text, a hidden port stem, a
hidden body conductor, transparent own channel polygons, an inherited hidden
marker and stylesheet-hidden ports.

The separate [eighth admission layer](eighth-bodies-visibility.py) rejects
all six while accepting the four original sources and their ten body/formal
bindings. [Exact evidence](eighth-bodies-visibility.json) preserves both the
unchanged fifth proof's acceptance and the new admission rejection. No prior
artifact, production file or source image was changed.

![Original and three visibility mutations](figures/bodies/eighth-visibility-controls.png)

I actually viewed this independent crop comparison. The absent text, absent
port stem and absent dashed body conductor are visible changes despite
unchanged primitive coordinates and raw node identities. The source images
used by the fifth study still contain the original visible objects.

The admission layer inspects the actual marker objects and their attached
labels, selected body glyphs and instance labels, actual conductor-ink paths,
contact dots, and their ancestor/subtree authority. Full-width rail owners
are logical route identifiers; their actual labels and conductor paths are
checked without inventing a symbol object for the owner.

The supported profile pins the exact source stylesheet, rejects additional
visibility/display/opacity/clipping/masking/filter/class authority, permits
only the observed font-style/weight inline declarations, and evaluates the
profile's simple inherited black/white/none paint attributes. Required text
must retain black fill; line/path primitives must retain black stroke;
filled/stroked shapes must have a supported visible paint. Positive stroke
and font sizes are required. The observed pixel font units are supported.

This is a bounded admission check, not a general CSS, occlusion, contrast or
visual-netlist engine. It does not prove perceived label association after
moving text, nor bring the seven fifth-study unassociated free/route labels
into its marker certificate. Unsupported presentation is explicit; it is
not silently projected back onto the original primitive coordinates.

The practical plan correction is at the evidence boundary: actual geometry
and supported rendering state are separate witnesses. Production layout
still consumes its own class/contact contract, not these source object IDs
or source CSS. Do not add a generic visibility flag to the hot netlist merely
to repair a research SVG adapter.
