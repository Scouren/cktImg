# Independent review of the bounded organization gate

The twelfth study supplies a useful local postcondition that whole-parent
translation cannot satisfy by itself. It does not establish an automatic
placement policy or complete drawing acceptance. The isolated native output
is a chosen default-library size reference; the original source geometry is
the independent evidence for the conditional row/column relations.

This review executes no new native command, compiler or host. It rereads the
saved artifacts and original sources, verifies their raw and physical role
bindings, and executes two offline geometry counterexamples. The exact replay
is `twelfth-review-organization.py --check twelfth-review-organization.json`
with paths relative to this directory, run from the repository root using
the full paths shown below.

## Exact raw and source denominator

opposite-polarity loads, transported reflection and complete external facts.
It agrees with the peer's exact six parents within the eleven complete acyclic
multigroup cases. All 2,202 disposition/name records and underlying deck hashes
remain checked; the other 2,191 cases are not shape-searched, so their empty
rows make no motif-absence claim. This establishes selector agreement on the
audited corpus and named control, not general equivalence for every possible
circuit. The
matching original decks are also reread through the separate body-study

devices, formal status and admitted rail identity; they are not reconstructed
from only the visible D/G/S contacts.

raw multigroup case but both shape selectors reject it. Removing only that

## What the native references prove

All six isolated decks preserve the five selected cards and all model and
parameter tokens. Their formal set is independently checked against every
original formal used inside the parent plus every net with outside incidence.
Outside devices are deliberately absent and their interfaces become formals.
Thus the isolated problem has different context and routing obligations.

The five common-control isolated runs produce a channel-center span/height of
140/150. That is a frozen diagnostic reference under the selected default
classes and layout options. It is not a source-derived universal width law,
an independent quality oracle for the same placement algorithm, a unique
optimum, or a proof that an identical footprint routes in the complete DUT.
Changing the library or pose capabilities requires a new bound or an explicit
decline; the numbers are not a generic pitch-independent policy.

The independent saved-output checks cover all six isolated and both full-DUT
runs: 94 complete MOS records, 376 raw D/G/S/B bindings and 282 visible role
coordinates. Every selected class, model/parameter sequence and actual pin
coordinate is compared with raw cards and the literal default-class transform.
Full-DUT cards, models and formals remain the original AG1080 ones; all 32
explicit pose requests in each run independently match actual origins and
orientations. These checks do not substitute for target netlisting.

Fresh actual views covered all five source/native pairs, six isolated PNGs and
both full-DUT controls, with paths and hashes recorded in the review JSON.
The translated AG1080 first parent visibly retains the stretched input bridge.
The reconstructed version has a compact local pair, while long wires still
connect it to the upper page. The PMOS input parent is compact too. Neither
image supplies a full-page improvement, final N0 partition or target claim.

## Two controls that bound the local predicate

Both controls copy actual reconstructed AG1080 records, preserve electrical
bindings and recompute every changed visible pin from the frozen default-class
transform. They are offline candidate records, not executed routes or target
schematics. Their original JSON files are retained under the bodies run's
`twelfth-review-organization/` directory.

* `rotate_input_180`: rotate M1 by 180 degrees at the same origin. Its channel
  center and all center-based relations remain unchanged; the original local
  gate passed. Actual D lies below S, reversing the source input role
  direction. Following review, the local gate now includes expected polarity
  and actual ordered D/S direction. The same literal now fails. The exact
  prior producer scripts and hashes are retained, and replay binds the old
  gate to its archived geometry dependency before confirming old-pass/new-
  reject. A valid caller-requested rotation remains authority to preserve or
  decline this narrow automatic trial; the trial does not rewrite it.
* `compress_rows`: place load centers at (0,0)/(2,0), input centers at
  (0,1)/(2,1), and tail at (1,2), retaining the actual default orientations.
  The local gate passes with span=height=2. Yet M1.D's own lead and M3.S's own
  lead overlap on x=0, y=[-19,-8], carrying different FN and VDD raw nets.
  This is an exact class-stroke overlap in the hypothetical candidate, not
  an electrical error observed in a delivered native or host output.

The peer promoted source-supported D/S direction into the local organization
relation. The compressed control remains a deliberate partial-gate limit.
The chosen upper size bound and source relations need separate class/contact,
clearance and whole-interface routing acceptance. The new local postcondition
must be conjoined with A/F/W and caller precedence. Mandatory N0 relations
cannot be waived because the local channels are compact. A positive local
score must never erase a failed body/contact, collision, partition or export
obligation, and `KEEP_INCUMBENT` remains fallback rather than achievement of
the promised new organization.
