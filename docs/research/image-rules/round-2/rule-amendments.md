# Proposed amendments to named current Human Rules

The table below names rules whose wording or responsibility should change
when the corresponding implementation package is proved. It is a proposed
amendment ledger, not an edit of the current headers. Current behavior must
remain accurately documented until code and its regressions change together.
The [frozen/current manifest](manifest.json) supplies exact source versions.

The serious recurring error is promoting a useful relation or fallback into
a universal drawing requirement: a graph symmetry becomes one compulsory
axis; a source pair becomes an independent rectangle; a recognized triangle
becomes permission to lay out its entire circuit. The observations support
conditional policies and explicit ownership instead.

“Retire” below means retire the stated human-rule justification or universal
scope. It does not mean delete the existing fallback algorithm. We do not
discard the 497 inventoried claims based on a handful of examples, nor
reassign historical 5,263-drawing frequencies to the 2,202-image corpus.

The [implementation packages](implementation-packages.md) connect these

removed to make an unsupported picture pass, and no fallback is retired
