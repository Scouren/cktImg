1. **A Q substrate is a real incidence.** `groups_candidates.terminals()` originally read every Q as three nodes. The literal `QX c base e s npnmod`, added to a two-MOS shared-source pair with tail at `s`, was silently truncated to C/B/E. Its substrate occurrence `[qx,3,s]` disappeared; `unsupported_cards=[]`, `reasons=[]`, and `shape_candidate_pending_ownership` survived. The independent model-aware body census contains 823 four-node Qs. None of their actual substrate nets hits an existing raw source region, so this attack does not claim an existing named shape count was wrong. The collector must parse full arity from declarations or explicitly decline ambiguous Q grammar. Silently treating an optional electrical terminal as absent invalidates “no unexplained incidence.”

2. **A partition is not an attachment-ownership proof.** The original AG459 certificate accepted reversing the two `owned` rows while leaving `cores` unchanged. It also accepted swapping I1/I3 or R1/R2 between the rows. All cards still appeared once, so the partition assertion passed. Actual source/native views contradict those mutations: R1/I1/I2 belong to M1/M2's source circuit, R2/I3/I4 to M3/M4's. The certificate needs each core inside its matching owned row and a role-aware raw-incidence witness for every extra owned resistor, tail, or current-source interface. A source geometry assertion over only the core cannot certify its extra attachments. Keep the expected manual ownership as an oracle, but test that malformed ownership manifests are rejected rather than merely reprinted.
