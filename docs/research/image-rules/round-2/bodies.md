# Round 2: body identity, visible contacts, and export contracts

The new rule boundary is **per ordered terminal, before placement**: preserve every electrical pin, then decide how each pin is represented. A MOS body cannot be hidden solely because it is the fourth pin, because its net is not an ordinary signal input, or because the source glyph has only three explicit leads. Conversely, a nonrail body is not automatically a separate visible input: B=S is common in local switches and MOS varactors. A body-only shared well also needs a representation. AG1294 MP7/MP8 is the fresh falsification: its net has only two body occurrences, the source draws their dashed connection, and the native picture omits it.

The [third body-only study](third-bodies.md) subsequently views every one of the 23 named internal body-only circuits and finds the necessary source-style exception: 22 draw the shared dashed bridge, but AG1236 omits it. The default representation and an explicit source-convention request must remain distinct; omission never licenses retieing or dropping B.

This is a research and implementation-plan document. No engine, plugin, ABI, committed wasm, or production selector was changed. The frozen executable remains `bf7b0749bde5822a68aa93fd9df69eb6e007dee0c24d5e9961ff65b187483560`. Twenty replays match the frozen gallery SVGs byte for byte. The proposed policy below is not implemented.

### Source identity is not the same as source geometry

For all 156 MOS rows in the 20 cases, the raw ordered D/G/S/B list exactly equals the source cache's named D/G/S/B map and the native JSON's ordered class pins plus `bulk`. All 468 D/G/S coordinates match actual transformed lead endpoints on a unique type/origin glyph. All 156 cached B coordinates are inside an actual filled channel polygon; **zero** are endpoints of an own fourth line/polyline lead. Sixty-six have actual named-net conductor ink ending at B; ninety do not. No studied named body route contains a cached segment lacking actual SVG ink.

These are separate claims. “B landing supported” means an actual conductor terminates at a supported place on the depicted glyph. It does not mean the glyph owns a fourth lead, and it does not independently prove that the source extractor assigned the intended raw card to the glyph. Forty-five actual labels are aliases, such as Q1, Cvar, S1, N5, or P0; they are retained literally. The raw-to-cache binding plus unique type/origin and three actual endpoints is the association certificate. An independent original editor/netlist export would be a stronger identity oracle; this study does not invent that artifact.

The body-path certificate retains every path to actual peer leads and supported body-polygon landings, using only SVG-backed named segments. Proper crossings connect only with actual contact dots. Disconnected named source pieces remain disconnected: AG1294's VSR-local pieces are joined by names in the drawing, not by a fabricated continuous wire. Explicit B-to-B net4 ink is continuous. A cached point, label, bounding-box overlap, or net name alone cannot create source ink. Peer review found and repaired a real gate hole: relocating AG1014 M1's cached B from `[124,110]` to the correct-net marker at `[60,110]` previously passed the ink-only status. The shared classifier now returns `detached_cached_body_landing`; the exact mutation is a regression control. A fourth visible class terminal with role `g` also now fails the canonical D/G/S/B binding checker. Arbitrary caller terminal names require an explicit ordered class schema beyond this proof's canonical names.

The checker does not independently bind displayed external label text to formal-port names. The peer's mutation of actual VI1 text to VI2 leaves the raw/cache and named-stroke certificate unchanged. This is an explicit limit, not a fully ink-certified formal-port identity claim. Before a future source-style importer treats that evidence as authoritative, it must reject contradictory actual marker labels or obtain an independent editor/netlist binding. Neither a text spelling nor a cache net ID resolves that contradiction by itself.

A frozen rule number reused by a current owner is not evidence that the frozen binary implements the current owner. ### Executed caller-contract experiment

`bodies_contracts.py` runs the frozen CLI on the literal card `M1 d g s b nm` plus `R1 b 0 1k`, with three explicitly supplied symbol sets: the original three-terminal class, a four-terminal class with a visible B lead, and the same four-terminal class with `hidden=true` for B. Every case preserves D/G/S/B. The first serializes B as `bulk` without a point. The other two serialize B as a class pin with an actual point. Only the visible fourth terminal receives a B-net route endpoint. Thus changing the final SVG alone is too late, and JSON `pins[].xy` alone is an insufficient visibility contract. This experiment changes only research input files under the run directory.

The code trace establishes why an isolated-looking resistor is not sufficient electrical evidence: the engine's no-connect pass counts routable pins; `tools/schemify/layout.zig` later names every hidden body and an otherwise unnamed wired peer, and suppresses a cross where a name is placed. This trace is not a successful executed Schemify round trip. A future change must run the actual host importer/netlister and `spicecmp` on all selected cards and hidden-body controls.

## Bounded implementation plan

Start with caller usage, not a renderer patch. A caller supplies classes and optional per-terminal presentation requests, places the deck, then reads a result containing all ordered electrical pins plus a separate contact/presentation view. The immediate API and the retained result must agree. Existing calls retain their compatibility policy until a deliberate default change is approved and tested.

1. **Parse and bind once.** The existing netlist owner produces ordered device offsets, pin nets, terminal roles, and complete incidence. Model/callee arity is validated at the boundary. Keep D/G/S/B even when equal, and preserve literal net identity independently of display labels. A missing or extra node is an operating diagnostic at import, never a coordinate fallback.
2. **Resolve caller policy and class capability.** The library owner knows whether a terminal has geometry, whether its geometry is hidden, and its role/side. A cold presentation transform reads explicit requests, semantic rail roles, all tie bits, and complete incidence. It writes one result per exceptional ordered pin. Precedence is explicit compatible caller request, caller class policy, then an opt-in inferred default. Conflicting or unsupported requests get named diagnostics. No silently replacing an authoritative caller class with a different four-pin symbol.
3. **Choose a bounded representation.** A visible body needs an actual class lead/contact or a caller-approved body attachment convention. B=S can use an explicit self-source convention while retaining the B binding. A semantically resolved rail body can use an explicit rail convention; source-equivalent style may instead request a visible local rail. B=D, B=G, a distinct external/internal body, and body-only shared wells have no implicit self-source exemption. If the class cannot represent a required body, preserve its electrical identity, emit an unresolved presentation diagnostic, and keep the safe existing drawing or an explicitly requested named fallback. Never fabricate a lead at origin.
4. **Finalize before geometry consumers.** Once the representation is resolved, construct routable pins, escape sides, reach, hidden-pin reservations, group boundary contacts, and wire requests. Every owner reads the same derived table. A visible body is an ordinary same-net contact with all body/foreign-net checks; a hidden body is still an electrical pin and may still reserve a true existing contact point. A missing-geometry pin has no physical coordinate to reserve merely because the legacy ABI returns origin.
5. **Place local body components only after visibility.** The narrow next cohort is a body net with exactly the named MOS B occurrence plus one resistor endpoint, with the resistor's other end semantically resolved to a rail/bias or another explicitly allowed boundary. AG1167/1169 supply evidence. Scan all raw occurrences before selecting a resistor, count all eligible and ineligible candidates, require unique ownership, preserve multiple-resistor/capacitor/body-peer variants as named declines, and evaluate actual endpoints. Do not fold AG1124's RC body networks into the two-pin rule. This study does not establish a universal resistor side, spacing, or orientation.
6. **Export through one contract.** `Placed`, JSON, C ABI, and Schemify receive identical ordered identity and resolved presentation. Host labels attach to real target contacts, not missing-geometry fallback origins. If hidden-by-name export is selected, every disconnected electrical island—including a body-only island—must have a target-valid name binding. Cross marks are a separate presentation result and must not suggest that a named hidden peer was deleted.
7. **Certify and commit atomically.** Build requested geometry and labels in caller-owned scratch; validate capacities, contact/frame constraints, ownership, explicit directives and export binding before replacing the old representation. Any rejected request leaves all prior device/net/presentation rows unchanged and writes a reason. No rollback repair after routing.

The six data questions constrain the eventual design. Cardinalities are E devices, P ordered pin occurrences, N nets, T class terminals, and K exceptional presentation requests with K≤P. The netlist owns electrical identity; the library owns immutable class geometry; one cold presentation owner writes resolved exceptions; geometry, wire and export owners consume them. Reads are per-pin sequential and per-net CSR slices; production predicates must not scan every device for each body. Existing typed u32 device/net/pin handles and their sentinel remain sufficient only while the existing capacity bounds are checked. Terminal index width must retain the declared device arity limit; do not narrow from this corpus's four-pin MOSs. A cold sparse exception table avoids a new boolean column on every hot pin; if measurements require a dense lookup, allocate once at P and state its byte budget before implementation. Error strings, evidence and rejection reasons belong in cold report rows. There is no SIMD, speed, or zero-residue claim in this research.

Three likely changes should have confined owners: a new caller four-pin glyph changes only class capability; a different self-source convention changes only presentation policy; another export target changes only the target adapter consuming the same result. If any of these requires rewriting raw incidence, the boundary is wrong. Do not add a new polymorphic framework: a closed presentation enum and borrowed table are sufficient for the real visible/hidden/missing-geometry cases here.

## Oracles, negative controls, and abstention

Executed checks are intentionally narrower than implementation acceptance. The raw census is pinned by independent handwritten D/G/S/B literals for AG1014,1021,1128,1130,1167,1177,1294. It runs actual mutated AG1014 input through the parser and the same binding checker: dropped B, swapped G/B, and B replaced by S all fail. Literal ties, simultaneous ties, card reorder, and bijective net renaming pass. The focused proof compares exact native bindings and rejects dropped bulk, swapped G/B nets, and a wrong G role in mutated JSON. Actual SVG controls remove the conductor, shift a cached D lead, and move a cached B off its conductor. Geometry remains unchanged by net renaming. These checks do not claim that a literal inequality alone detects a production mutation.

Before implementation acceptance, add independent target-netlist round trips for B=S, B=D, B=G, distinct external body, rail body different from S, mixed per-net visibility (AG1181), all D=S=B ties, each local body resistor, and the body-only AG1294 well. Compare exact named cards and every ordered pin, not just counts or graph isomorphism that could swap G/B. Mutations must delete/swap the fourth exported terminal, change a hidden label's net, move it off the target contact, and omit the visible peer's label. Each must fail the independent host round trip or a contact oracle. The existing hidden class and explicit caller four-pin visible class are mandatory controls.

Visible acceptance needs actual stroke attachment and same-net path or valid target name attachment for every required body, not JSON coordinates alone. A mutation that moves B onto an unrelated same-net wire must fail the own-glyph contact gate; removing a fourth lead while leaving its metadata must also fail. Source polygon landings are a separately named convention and cannot pass a fourth-lead oracle. Rotate/mirror all cardinal poses; preserve ordered net identities and caller constraints. Add class-hidden versus absent-terminal cases, source alias labels, rail-name renaming with transported semantic roles, duplicate terminal occurrences, unsupported model/callee arity, body-only wells, and extra raw body/control incidences.

Abstain from inferred geometry when source identity is ambiguous, cached coordinates miss their actual glyph, a class has no supported body contact, rail meaning is unresolved, caller constraints conflict, local ownership overlaps, or raw incidence is incomplete. Retain those rows and report them; do not quietly remove a difficult case from the denominator. Preserve the existing electrical row even when source presentation is unsupported. A missing source lead is not evidence of an electrical omission, and a native no-connect cross is not a substitute for the target-netlist oracle.
