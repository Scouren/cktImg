# Twelfth study: a finite local organization trial

There is a useful first G1 experiment smaller than a general page arranger:
reconstruct a complete five-MOS input stage with one common external control,
then protect its local rows and branch spacing from unrelated global columns.
Inside the eleven original acyclic multigroup candidates, five such parents
occur in four circuits. Their sources support a small set of relative
organization relations. Two actual full-DUT AG1080 caller-pose experiments
separate whole-parent translation from local reconstruction: translation
retains the stretched geometry; reconstruction satisfies the local relations
and a fixed diagnostic footprint. Neither is a successful whole-page layout.

This is an **unimplemented, bounded default-class trial**, not a five-MOS
human-layout law. The broad topology already has an actual contrary, AG1028.
The local checker is deliberately only one acceptance gate: it now checks
actual D/S direction as well as centers; symbol/lead clearance, contacts,
routing and physical net parts must pass independently before publication.

## Exact domain and raw admission

[The probe](twelfth-organization-probe.py) rereads all 2,202 actual original
decks with the ninth collector and checks every returned field against its
saved census. It preserves all seven disposition-name sets. It searches the
five-MOS shape **only inside these eleven** `raw_multigroup_candidate` cases:

`ag-1016, ag-1028, ag-1046, ag-1047, ag-1051, ag-1071, ag-1075, ag-1077,
ag-1079, ag-1080, ag-364`.

The other 2,191 cases are explicitly recorded as **not shape-searched**. Empty
rows for them do not assert shape absence. This is a first multistage trial
boundary, not a full-corpus five-MOS motif census. In particular, AG928's
single-core disposition is a keep, not proof that it lacks similar subgraphs.
The O0 input, model, complete-involution, rail, body, attachment, cycle and
search-completeness boundaries remain those of
[ninth-local-groups.md](ninth-local-groups.md). No new cycle law is proposed.

Within that domain, collect every complete five-member parent meeting all
of these conditions before considering coordinates:

1. Two same-type input MOS devices are exchanged by the complete involution.
   Their sources share one private net. Its **entire D/G/S/B incidence** is
   precisely the two input sources and a self-mapped tail drain.
2. The tail has the same MOS type as the inputs, and its source and body
   share one admitted rail. Two opposite-type load devices are mates; each
   shares a drain net with exactly its associated input within this parent.
   Their source and body share the other admitted rail. These five devices
   exhaust the certified parent; no passive, hidden body attachment or
   additional owner is silently absorbed.
3. The two input gates are distinct DUT formals. The loads share a formal
   gate; the tail gate is a formal. Input gates differ from both controls.
   Every raw occurrence of an input/control formal is a G occurrence.
   Both branch drain nets are private, nonrail nets. Full external drain,
   gate, rail and body incidence is retained, even when it leaves the parent.
4. The **narrow first trial** additionally requires tail.G = both load.G.
   This is net identity, not a name-based clock classification. Equal full
   model/parameter and signed terminal bindings come from the certified
   involution; type names alone do not establish matching devices.

## Independent observations and the deliberately limited metric

All eleven original source/native pairs plus AG928 were actually viewed
again, followed by six isolated and two full-DUT native controls: twenty
image files, thirty-two panels. [The view ledger](twelfth-organization-views.json)
records exact hashes and observations. Source channel stubs were reread from
actual original SVG ink and checked against the source device binding. This
retains the extractor's **viewed frozen-original coordinate subset** scope;
it is not an arbitrary edited-SVG visibility or CSS validator. The independent
[review](twelfth-review-organization.md) additionally binds ordered source
D/G/S roles, rather than inferring direction from an unoriented channel.

For each of the five common-control parents the actual source has:

* upright channel stubs and two distinct branch columns;
* each input in the same channel column as its associated load;
* equal input rows and equal load rows;
* the tail channel strictly between the two branch columns;
* loads, inputs and tail ordered by polarity: load→input→tail downward for
  NMOS inputs, with the vertical order reversed for PMOS inputs.

The exact tail midpoint is **not** a source requirement. In AG1080 the M1/M3
and M2/M4 channel columns are −170 and −90, whose midpoint is −130; M5's
channel is at −120. Its ten-unit offset is real. The chosen native controls
center the tail as a canonical implementation choice. Gate-facing choices
remain another decision; these observations do not require every mate glyph
to be mirrored.

The independently role-bound source reader verifies one further relation
for all thirty selected source glyphs: NMOS S.y > D.y and PMOS S.y < D.y.
The strengthened local gate requires this direction on the actual ordered
D/S contacts, with the expected selected MOS type, for each member. A valid
class rotation alone is insufficient; a 180° rotated input has the wrong
directed interface for this narrow upright trial. A conflicting original
caller pose requires compatibility or decline, not automatic correction.

AG1028 falsifies the broader equal-input-row proposal. Its two input channel
centers have y=140 and y=180. Its separately controlled tail/load stage is
outside the narrowed trial. The isolated engine aligns it anyway, providing
a direct warning against treating an isolated engine output as the human
oracle. Common control is a bounded observed distinction for this first
family, not a demonstrated causal explanation or universal classifier.

The [actual AG1028 source/native pair](figures/groups/ninth/ag-1028-pair.png)
shows the staggered source inputs and aligned native inputs side by side.

For the first default-class literal, freeze width ≤140 and height ≤150 as a
**chosen diagnostic reference**, measured by the six separate frozen runs
before implementing G1. The class unit is 40; these are 3.5 and 3.75 units.
They are not inferred human scale, a global width threshold, an optimum or
an independent feasibility proof. Different selected frames, caller spacing
or layout values require a separately supported capability or an explicit
decline; they do not silently inherit these constants.

The local checker reads actual output contact coordinates, never a candidate's
H/V syntax or self-reported box. It checks the six relative measurements above,
the actual directed D/S roles and the fixed extents. Output cannot pass merely by saying that a
local reconstruction ran. The reference remains frozen; rerunning a changed
placer must not move the acceptance bound. Its independence is a **literal
test obligation**, not evidence that the old isolated engine chose the best
human drawing. Source relations, raw role bindings and full feasibility use
their separate oracles.

Two tempting substitutes fail concretely. Whole-parent translation preserves
the old extents, so cannot repair them. Counting local lattice columns also
misses physical stretch: AG1080's PMOS inputs already occupy nearby lattice
columns 56/72, yet their physical channel span is 260. Current physical
column widths include reach, ports and name reservations of other devices in
those global columns. A useful local reconstruction must protect a local
physical metric as well as relation/order, with its full external interfaces
still represented.

## What the actual experiments prove

Six isolated decks preserve each selected complete five-device parent and
its exact ordered models/parameters. Every original formal incident on that
parent remains a formal; every touching private net with outside incidence
becomes a projected formal. The saved `complete_boundary` still records
those outside consumers. Each record lists all removed ordered device cards,
omitted original formals and newly exported nets.

Isolation removes outside glyph poses/ink, route/name reservations, parent
dependencies, page composition and the original full-DUT port geometry.
Synthetic projected ports can alter the isolated engine's spacing. These
decks are not electrically equivalent to the original whole DUT, and their
small footprint is not a routing certificate in that DUT. A production path
must not generate projected SPICE text and recursively invoke the engine to
obtain a supposedly authoritative local box.

The two full-DUT experiments retain all thirty-two AG1080 cards, all four
ordered terminal bindings, complete model/parameter identities and original
formals. They use explicit `at` hints for every device. The remaining
twenty-two device poses stay exactly at their original native positions.

* **Translate:** move each of the two complete five-device parents without
  changing any internal pose. Both local gates still fail: 940×180 and 260×180.
* **Reconstruct:** translate the two isolated reference poses into the full
  DUT. Both pass the local partial gate at 140×150. All sixty-four raw MOS
  contracts across the two executions, their actual selected-class D/G/S
  contacts and all sixty-four honoured `at` requests are checked directly.

Compare the actual [translated output](figures/groups/twelfth/ag-1080-translate.png)
with the [locally reconstructed output](figures/groups/twelfth/ag-1080-reconstruct.png).
These are generated diagnostic images from the retained full-DUT decks, not
new human references.

The reconstructed drawing visibly has compact local stages at the bottom,
but long external interfaces and the other twenty-two flattened devices
remain. It is a feasible **caller pose expression and raw-binding witness**,
not a full-page quality or A/F/W acceptance certificate. No automatic
admission, new N0 partition, host import or source-equivalent drawing was
executed. These strong explicit hints are diagnostic controls; a future
automatic trial must instead respect or decline relevant original caller
authority.

The [independent route review](twelfth-ports-route-review.md) makes one
remaining failure concrete: in the reconstructed full-DUT output, RN, RP and
FP1 each still form one continuous three-pin piece, while FN1 remains three
named singles. All four fail the eleventh source-certified D/D-plus-separate-G
2+1 requirement, even though both selected local organization gates pass.
This is a required physical-part failure, not proof of a wrong electrical
net. Suspected cross-net joins in the raster were corrected by actual SVG
and route inspection: FN/FP cross undotted at (570,630), while the nearby FP
dot is at (570,635); RN1/RP1 crossings are also undotted. The review found no
cross-net route contact in its stated exact geometry scan. Neither that scan
nor the raw identity proof closes the failed N0 obligations or every A/F/W
quality gate.

The proof also rejects doubled local x spread, one staggered input, a tail
outside the two branch columns, a broken input/load column and a frame-valid
180° input rotation. Translating a compact whole parent preserves the pass.
The independent reviewer retains two originally passing controls: compressed
two-unit columns/rows overlap different-net leads, and a 180° input rotation
preserves centers but reverses D/S direction. The latter exposed a missing
directed relation and now fails the strengthened gate. Its actual predecessor
proof/probe bytes, JSON and hashes are preserved under the run's
`groups/twelfth-pre-direction` directory; the reviewer retains old-pass/new-
reject evidence. The compressed control still passes this partial local
gate, proving why body/lead clearance, foreign contact, router and name
checks remain required. Both controls preserve raw bindings and valid class
transforms. No CLI or target electrical failure is inferred from them.

## Concrete first implementation owner and acceptance sequence

This adds a bounded child-organization proposal to G1, not a new global
symmetry rule. Keep the existing global device/net mate relation. Do not
reinterpret `skeleton.axis2`, change parent membership to reduce width or
make every parent a rectangular proxy. O0 supplies complete owners/interfaces;
C supplies validated original authority; G owns local row/column proposals;
F/W/N retain their frame, routing and physical-part decisions as described
in [implementation-packages.md](implementation-packages.md) and the
[N0 transaction contract](n0-implementation-contract.md).

The smallest production experiment can proceed as follows:

1. Admit only the named structural **predicate**, within the complete O0
   multigroup domain, with the supported default MOS frames and layout
   capability. Read full boundary rows, not an induced five-device graph.
   Missing cold context, exhausted ownership search, unknown original caller
   intent or unsupported geometry leaves the raw candidate visible and
   declines the automatic proposal.
2. Before global `columns.order`/`sequence.columns` and wrap, construct two
   input/load branch chains and a separate tail row in local lattice space.
   Enumerate the two reflected branch assignments with the polarity-specific
   row order, plus KEEP_INCUMBENT as rollback. Compute physical local gaps
   from the supported selected frames and spacing. A local parent origin
   owns translation; later column packing may not independently stretch its
   member coordinates. This is a five-member local room, not a universal
   disjoint-box or whole-page direction requirement.
3. Carry every external gate, output, rail and body incidence into full-DUT
   frame/reservation/routing work. Complete raw inventory, role coordinates,
   actual D/S direction, body/lead occupancy, caller contracts and mandatory
   N0 obligations are hard constraints. Preserve caller ports, spacing and
   naming reservations; do not relax them to meet the diagnostic footprint.
   Original `at`, axis, symmetric, group or stack requests touching the
   proposal require a directly verified compatible result or an explicit
   decline. Initial conservative decline is sufficient; an honoured report
   alone is not a geometry oracle.
4. Evaluate the source-supported local relations and the chosen fixed
   default-class extent bound on actual final contact coordinates. Then
   check all A/F/W/N requirements, including late thinning. A compressed or
   reversed member cannot be accepted merely because the local check passes.
   If outside context makes the small footprint impossible, report that
   obstruction and decline or require a wider G1 composition; do not silently
   enlarge this acceptance bound or downgrade a required N0 part.
5. Rank only complete feasible alternatives under the documented bounded
   heuristic. Record which candidate and budget were tried. Unique human
   preference and global optimum are not required. KEEP_INCUMBENT remains a
   rollback even if it fails organization; selecting it is **no improvement**.
   Later compaction/wrap/caller writers must preserve the checked local
   relations and bound, or withdraw the complete proposal and its dependent
   routed/named state. An append-only wire checkpoint does not restore
   moved devices or every reservation by itself.

The two branch assignments need no source-ID dispatch and no newly exposed
axis API. Their local pose feasibility does not decide where all parents go
on the page. The tenth finite composition work remains a separate layer.
AG1016 interleaving, AG364 nesting and AG1047/1051/1075/1077 vertical or complex
stages remain outside this initial local reconstruction; preserve their raw
parents and current ordinary paths. AG928 stays one core. AG1028 stays the
explicit staggered-input contrary. None is declared aesthetically solved.

## Finite finish line and remaining work

A first **local native G1 milestone** is now operational: all five selected
parents in AG1046, AG1071, AG1079 and AG1080 satisfy the declared default-class
local relations and channel-center extents on final coordinates, together
with the independent hard checks above. Exact source role/order and fixed
bound fixtures must be red on the frozen stretched cases before the new
path is trusted. All original eleven O0 dispositions, the contrary/keep set,
caller controls, raw alias/mutation controls and rename/card-order relations
remain explicit acceptance obligations. Neither source IDs nor measured
source coordinates are runtime inputs.

This would be a concrete partial improvement to the user's global-core
problem. It would **not** establish compact organization of all five AG1080
parents, reproduce the full source drawing, or close the six-net N0 milestone.
Where N0 is advertised, all six required conductor/name partitions still
must pass atomically as specified by the eleventh study. Native and actual
same-build target gates remain separate. New symbol contracts or diagonal
capabilities are not prerequisites for collecting or trying this MOS-only
proposal.

Still unexecuted: an automatic local owner integrated before global columns,
the five full-context accepted placements, independent clearance/foreign-
contact/routing gates, original-caller compatibility and late-writer rollback,
required N0 parts after moves, same-build plugin transport and actual target
organization. The eight frozen CLI executions establish the limited
references and pose controls above; they do not fill those gaps.

Relevant proposed-rule scope is `symmetry.1,5,7`, `structure.3–11`,
`wrap.1–4,7–11`, and the local-vs-physical distinction in `sketch.14,15` and
`wires.17–19`. This study narrows a future path under those rules and leaves
their current implementation unchanged.
