# Human layout rules and their production evidence

The rule numbers refer to the 27 proposals in the layout research. Their scope ranges from electrical invariants to choices that differ between two drawings of the same circuit. A source diagram establishes a possible arrangement. The ordered SPICE pins establish what must stay connected. Several converted decks can originate from the same figure.

| Rule | Production result | Evidence or remaining limit |
|---|---|---|
| P01 · Recognize complete symbols | Three four-bias amplifiers and four clocked comparators gain distinct glyphs. Each variant requires its complete role set. A different complete contract can still select another glyph, and unknown controls retain their explicit representation. | Seven instances, 50 declared formals. VB4 is the ninth formal in the three nine-pin decks. Separate port-order tests put an output in slot nine. [Analog symbols](README.md#four-bias-amplifiers-and-clocked-comparators) |
| P02 · Keep auxiliary terminals | An omitted supply lead in a reference drawing still has its declared connection in production. A genuinely global supply adds no new formal. | The reference redraws show 43 of the 50 leads. AG3495 has five formals. [Analog symbols](README.md#four-bias-amplifiers-and-clocked-comparators) |
| P03 · Order signed inputs in the symbol frame | When the amplifier directly drives the NMOS pass gate, its private feedback divider and series output C/ESR qualify the six-device regulator for positive reference above negative divider tap in the canonical frame. | Forty decks share one published example. An independently published rotated frame puts the reference on the left. [Regulator comparisons](README.md#signed-inputs-on-a-regulators-error-amplifier) |
| P04 · Select facing independently | Fixed caller rotations transform the full symbol. Canonical PFD and DAC sides follow named roles regardless of declaration order. Electrical binding retains the declared sequence. | AG1242 and the DAC examples still differ in whole-sheet facing from the originals. [Boxes and port sides](README.md#named-contacts-on-pfd-and-dac-boxes) |
| P05 · Keep unknown functions explicit | AG808’s IB-controlled amplifier retains its box alongside a recognized clocked comparator. PFD/DAC instances retain box outlines. | A name prefix or one conventional pin name is insufficient. [AG808](README.md#four-bias-amplifiers-and-clocked-comparators) |
| P06 · Preserve shared definitions | Native regulators and samplers can use different signed frames for one electrical definition. Schemify updates the shared generated symbol when every use qualifies. | Mixed Schemify uses keep their common default so every instance still opens and netlists the original implementation. [Before, after and ordered host checks](shared-frames/README.md) |
| P07 · Preserve ordered occurrences | Electrical checks trace the original pin index even when two or more pins of one device have the same net. | The body study below covers simultaneous ties. The comparator checks include every MOS model and parameter. [Target regression](../../../tests/parent_output_routes.py) |
| P08 · Resolve body presentation per occurrence | Native three-contact symbols retain the fourth net as `bulk`. Four-contact symbols can route an exposed B. Hidden contacts follow the supplied class policy. | AG1181 contains both source-tied and distinct bodies on Vb. [Converted deck](../../../external/examples/analoggenie/ag-1181.cir) |
| P09 · Represent a private shared well | A supported four-contact class can join or name both B pins. Two-body membership alone leaves the original author’s presentation ambiguous. | Of 23 reference redraws, 22 show a dashed bridge and AG1236 omits it. [AG1294 redraw](../../../external/examples/analoggenie/ag-1294.svg) · [AG1236 redraw](../../../external/examples/analoggenie/ag-1236.svg) |
| P10 · Require an actual contact | The stock native class has no B coordinate. The shipped Schemify core MOS exposes B. A caller-provided four-contact native symbol supplies a real landing. | The three-contact native drawing can omit a meaningful body-to-body relationship. The body’s net survives export. [Selected symbols](../../../tests/symbols.zon) |
| P11 · Tell hidden peers from lone pins | An otherwise unmarked visible terminal on an automatically styled internal net gets the shared name when all its peers are hidden. Rails, ports and caller-styled nets retain their own presentation. A truly isolated terminal keeps its cross. | Twenty-six false crosses corrected in 14 decks. [Before, after and original](README.md#a-hidden-body-still-connects-to-its-resistor) |
| P12 · Collect degeneration paths | The source-region census collects all MOS sources on a direct or resistor-linked region before selecting a pair. | It retained 1,498 regions in 1,146 supported decks. AG558 has two triples. [Memberships](source-regions/README.md) |
| P13 · Prove attachment ownership | Exact ordered endpoints, resistor values, tail or current sources, rail polarity and outside incidences identify a branch. Two compatible equal arms can meet over the tail. | AG220 and AMS-Net 530 each gain the horizontal T. Both reproduce one published composition. Their source and converted bulk connections are documented separately. [Two-arm bridge](two-arm-bridge/README.md) · [Single-arm and current-source controls](source-regions/README.md) |
| P14 · Keep nested pairs distinct | Disjoint memberships survive overlapping geometric extents. | AG517 keeps separate inner/outer pair identities. Their full placement still differs from the original. [AG517 comparison](source-regions/README.md) |
| P15 · Retain alternative quad arrangements | The selector admits two locally reflected input branches when the complete interface fits. | Evidence also includes nested, staggered and two-dimensional quads. AG1093’s layout is outside that selector. [AG1093 redraw](../../../external/examples/analoggenie/ag-1093.svg) |
| P16 · Treat shared nets as interfaces | Ordered D/S connectivity defines local MOS groups. A control gate linking two such groups is recorded as an interface. | AG1080 has five groups and AG928 one. [Stage membership](README.md#identifying-local-stages-from-a-netlist) |
| P17 · Preserve competing witnesses | Automatic layout requires a unique supported local reflection or complete branch ownership. Incompatible raw competitors stay visible in the census. | Tests compare named outcomes and complete incidence witnesses across 2,202 inputs. [Census regression](../../../tests/parent_corpus.py) |
| P18 · Recheck caller symmetry | Requested mirrors, axes and written stack order are checked against the final physical terminals. Strong fixed poses take precedence and can invalidate a mirror. | Includes two distinct tail sources, a branched three-MOS stack and an ordered pair of opaque blocks in different columns. [Caller drawings](caller-symmetry/README.md) |
| P19 · Keep local circuits legible | Two load/input columns and an interior tail make five common-control stages locally traceable. The five-stage span and whole-page costs are reported separately. [Stage comparisons](common-control/README.md) · [Filter and sampler gallery](README.md#passive-ladders-and-bridged-t-filters) |
| P20 · Choose wire pieces and names separately | Six intermediate outputs each join two drains and separately name a remote gate. Cyclic controls keep their continuous wires. A bias port can use a clear adjacent tap after routing. | `*@ wire` and `*@ label` still request different physical partitions. [Output traces](parent-outputs.md) · [Bias tap](README.md#a-visible-bias-feed-between-two-gates) |
| P21 · Admit diagonals only with end-to-end support | The current engine, C ABI and editor adapter use Manhattan segments. | P22 · Evaluate glyph orientation separately | The sample-and-hold bridge uses four cardinal diodes and preserves every anode and cathode. | AG493’s oblique capacitor bodies need a different symbol transform. [Physical regression](../../../tests/parent_output_routes.py) |
| P24 · Respect admitted caller requests | Local stages and partitions defer to admitted requests on the affected devices or nets. Rejected or unrelated text can coexist with the automatic outcome. | Includes weak stays, fixed poses, explicit wires/labels and target/symbol overrides. | P25 · Check the actual frame | Layout checks the selected symbol’s physical contacts and measures the completed native and target geometry. ## Where published drawings make different choices

A divider feeding a MOS gate already had a straight tap-to-gate conductor in all twelve reviewed cases. In thirteen op-amp feedback cases, the default upper-minus symbol gave twelve continuous horizontal upper returns. Selecting a lower-minus caller class retained the signed inputs and gave twelve continuous lower returns. AR3201 exports VDDL to additional circuitry. The published feedback resistor occupies the lower horizontal leg in ten and an upright output-side leg in three. The two input wires of an outward-facing pair also need separate judgment. AG333 and AG978 bring both signals in from the left. AG1028 staggers the input devices. [AR5143 horizontal feedback resistor](https://huggingface.co/datasets/eulermaxwell/AnalogRetriever-data/resolve/0c053b6580315d8a89c629d67994a6da4575a17f/iccad2026/images/img5143.jpg) · [AR1316 upright feedback resistor](https://huggingface.co/datasets/eulermaxwell/AnalogRetriever-data/resolve/0c053b6580315d8a89c629d67994a6da4575a17f/iccad2026/images/img1316.jpg) · [AR3201 redraw](../../../external/examples/analogretriever/ar-3201.svg) · [AG333 redraw](../../../external/examples/analoggenie/ag-333.svg) · [AG978 redraw](../../../external/examples/analoggenie/ag-978.svg) · [AG1028 redraw](../../../external/examples/analoggenie/ag-1028.svg)

In the native body study, 780 MOS devices across 39 DUTs preserved every ordered D/G/S/B under three class contracts. For the 23 private wells, a routable four-contact class joined both actual B tips in 22 drawings. AG2287 used two named pieces and joined them with an explicit `*@ wire net4`. Nine actual Schemify imports preserved all 416 ordered MOS occurrences on 104 devices. The four isolated D/S terminals in AG1130 acquired distinct host-generated net names. The stock three-contact native class leaves private body relationships implicit. [AG2287 deck](../../../external/examples/analoggenie/ag-2287.cir) · [AG1130 deck](../../../external/examples/analoggenie/ag-1130.cir)

AG1080’s published drawing uses three panels. The five identified groups and two compact input stages fit on a single generated sheet. Interleaved groups in AG364 and AG517 show why a general rule that boxes every group or orders all groups left to right would fail. Similarly, AG1146’s one displayed bus landing represents four scalar ports. The current outputs keep those four electrical contacts distinct.
