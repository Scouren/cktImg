# Testing

What "correct" means here: the drawing shows the same circuit as the deck (nothing open,
nothing shorted), nothing overlaps, and it shows the relations the statements and the
baseline ask for. The main bug class is a drawing that is wrong with no crash, so every
layer below names its **oracle**: the independent thing that says the output is wrong.

    python3 -W error -m unittest discover -s tests -t .      # everything below marked "commit", about 3 s

## Bug class, oracle, layer

| bug class | oracle | where |
|---|---|---|
| a net is open, or two nets are shorted, in the drawing | `gates.extract` reads the nets back from the finished geometry and names alone (segments that touch, pins on segments, things that carry one name) and compares them with the deck. It shares no code with the placer or the router | every `draw()`; `tests/test_fixtures.py` on every deck; the corpus sweeps |
| two symbols overlap; a wire enters a symbol | `gates.check`, from the boxes the symbols cover | the same |
| the gates themselves miss a violation | seeded violations: a legal drawing damaged in one known way (a wire removed, two nets bridged, a crossing, a symbol moved onto another, a wire through a symbol) must be reported, and as that kind only | `tests/test_gates.py` |
| the drawing does not show a relation it was asked for | `judge.holds`, which was fitted to 5,232 hand drawings before this tool existed and reads geometry only | every `draw()` (the read-back's `[NOT SHOWN]`); the sweeps count them by rule |
| the contract promises something people do not draw | the people's drawings: how often each rule holds in them | `tools/corpus.py --people` |
| a circuit loses its textbook shape (no X on a cross pair, a latch off its axis, compensation on the wrong side, a Gilbert cell's pairs not over its input pair) | spec examples: facts read off the textbook drawing, checked on the drawing JSON | `tests/test_shape.py` |
| a wiring default is not applied (ground symbol, supply bar, far nets by name, a declared signal wired) | the convention as counted on the corpus, checked through `net_pieces`, which `gates.pieces` reads back from geometry | `tests/test_wiring.py` |
| the same input draws differently twice | byte equality of two runs, and of two processes with different hash seeds | `tests/test_fixtures.py`, `tests/test_cli.py` |
| a position depends on a net's name | metamorphic: renaming an inner net moves nothing | `tests/test_fixtures.py` |
| the deck reader misreads a card | hand-written decks whose devices and nets are known | `tests/test_netlist.py` |
| the manual shows something the tool does not do | the manual's read-back example and its op-amp statements are compared with a real run | `tests/test_cli.py` (`Manual`) |
| a drawing changes without anyone meaning it | a golden: `docs/gallery/*.svg` is byte for byte what the tool draws now. Provenance: the tool's own output, regenerated by `python3 tools/gallery.py`. It shows a change in review; it does not judge one | `tests/test_cli.py` |
| the oracle comes to depend on what it judges; a file outgrows 500 lines; a public item has no docstring | the import graph of `gates`, `judge`, `contract`; `tools/check.py` | `tests/test_cli.py` (`HouseRules`) |
| a crash, or an illegal drawing, on a circuit nobody thought of | 5,232 real decks, each drawn and passed through the gates | `tools/corpus.py` (nightly) |

A bug a person finds is a hole in this table. It lands with its regression test and, where
it has one, the oracle that would have caught its class. Two came from the corpus sweep and
each left a fixture behind: `tests/decks/latch.sp` (two Xs on the same nets were taken for
one joined piece: an open net) and `tests/decks/clamp.sp` (a loop of series parts put two
pins on one point: a crash). Both fail on the commit before their fix.

## Tiers

| tier | budget | what runs |
|---|---|---|
| commit | under 10 s | `python3 -W error -m unittest discover -s tests -t .` (43 tests, about 3 s): fixtures, gates, shapes, wiring, reader, command line, manual, house rules, gallery |
| nightly | about 40 min | the corpus sweeps below. The corpus is third-party data and is not in this tree: pass its path |

The corpus is untrusted input: the sweeps run under `python3 -I` and take its path as an
argument.

    E=/path/to/external/examples
    python3 -I tools/corpus.py $E --statements tools/statements       # the 48 blind files, 25 s
    python3 -I tools/corpus.py $E --split test                        # held-out, no statement
    python3 -I tools/corpus.py $E --split test --stand-in             # held-out, statements read off each drawing
    python3 -I tools/corpus.py $E --split train                       # the other 4,207, for crashes and illegal drawings
    python3 -I tools/corpus.py $E --people --stand-in --split test    # the contract against the people's drawings

Each prints: drawn, legal, illegal by gate, relations shown and not shown by rule, terminals
joined by name for want of a path, crossings and corners beside the people's. The exit
status is 1 when a deck crashed or a drawing is illegal.

## Exit criteria

A change ships when a script says all of these:

- the commit tier passes with `-W error`;
- `python3 -I tools/corpus.py $E --split test` and `--split train` exit 0: no crash, no
  illegal drawing, on all 5,232 decks;
- relations shown on the blind set do not fall below the last recorded count, and no rule's
  share in the people's drawings (`--people`) falls;
- the numbers that moved are in the commit message.

The recorded numbers are in `README.md`.

## Known gaps

- **Quality has no oracle.** Legality and the contract are checked; whether a drawing reads
  well is measured only by proxies (crossings, corners, terminals joined by name) and by
  looking at `docs/gallery/`. The proxies still trail people: see the README.
- **`judge.holds` is trusted, not proven.** It was fitted on hand drawings; a relation it
  misjudges on the tool's own drawings would go unseen.
- **The golden is the tool's own output.** It catches change, not error.
- **No fuzzing of the deck reader.** It is exercised by 5,232 real decks and three written
  ones; a malformed deck is reported line by line, but that path has no generator behind it.
- **Held-out data is no longer unseen.** The 48 blind circuits and the first 300 held-out
  circuits were looked at while the placer was built; the README says which numbers that
  touches.
